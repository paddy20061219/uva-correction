# UVa 272 - TEX Quotes 訂正紀錄

## 一、題目重點

UVa 272 要求把文章中的普通雙引號 `"` 轉換成 TeX 使用的左右雙引號。

轉換規則：

1. 第 1 個 `"` 要換成兩個左單引號
2. 第 2 個 `"` 要換成兩個右單引號
3. 第 3 個 `"` 再換成兩個左單引號
4. 第 4 個 `"` 再換成兩個右單引號
5. 依照這個規則一直交替下去

除了雙引號以外，其他所有字元都要原封不動輸出，包含空白和換行。

---

## 二、原本錯誤程式碼

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;

    while (cin >> s) {
        bool open = true;

        for (int i = 0; i < s.size(); i++) {
            if (s[i] == '"') {
                if (open)
                    cout << "''";
                else
                    cout << "``";

                open = !open;
            } else {
                cout << s[i];
            }
        }

        cout << endl;
    }

    return 0;
}
```

---

## 三、錯誤原因

這份程式有幾個主要錯誤：

### 1. 使用 cin >> s 會吃掉空白

原本程式使用：

```cpp
cin >> s
```

這樣只會讀取一個單字，遇到空白就會停止。

可是 UVa 272 要求輸出要和原本輸入幾乎完全一樣，除了雙引號要改掉以外，空白和換行都要保留。

所以不能用 `cin >> s`，應該改用：

```cpp
cin.get(c)
```

一次讀一個字元。

---

### 2. 每讀一個單字就重新設定 open

原本程式把：

```cpp
bool open = true;
```

放在 while 迴圈裡面。

這樣每讀到一個新的單字，open 都會重新變成 true，導致引號判斷錯誤。

正確做法是讓 open 在整篇文章中持續交替，不能每一行或每一個單字重新開始。

---

### 3. 左右引號輸出相反

題目規定第一個雙引號要輸出兩個左單引號，第二個雙引號要輸出兩個右單引號。

但原本程式把第一個輸出成兩個右單引號，順序剛好相反。

---

### 4. 自己多輸出換行

原本程式每讀完一個單字就輸出：

```cpp
cout << endl;
```

這會讓原本同一行的句子被拆成很多行。

UVa 272 的輸出格式必須保留原本的換行位置，所以不能自己隨便加換行。

---

## 四、訂正後正確程式碼

```cpp
#include <iostream>
using namespace std;

int main() {
    char c;
    bool open = true;

    while (cin.get(c)) {
        if (c == '"') {
            if (open)
                cout << "``";
            else
                cout << "''";

            open = !open;
        } else {
            cout << c;
        }
    }

    return 0;
}
```

---

## 五、訂正後改善的地方

訂正後改成使用：

```cpp
cin.get(c)
```

一次讀一個字元，這樣就能保留空白、換行和其他符號。

另外，`open` 放在 while 迴圈外面：

```cpp
bool open = true;
```

這樣可以讓雙引號的狀態在整份輸入中持續交替。

當讀到第一個雙引號時輸出兩個左單引號，當讀到第二個雙引號時輸出兩個右單引號。

最後用：

```cpp
open = !open;
```

讓狀態在左引號和右引號之間切換。

---

## 六、心得

這題雖然程式不長，但是很容易因為輸入方式錯誤而 WA。  
我原本使用 `cin >> s`，導致空白被吃掉，輸出格式完全不符合題目要求。  
訂正後我學到，如果題目要求保留原本文章格式，就應該使用 `cin.get()` 一個字元一個字元讀取。  
另外，像這種左右狀態交替的問題，可以用一個布林變數來記錄目前應該輸出左引號還是右引號。

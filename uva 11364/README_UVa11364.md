# UVA 11364 - Parking 訂正

## 題目重點

這題是在算停車後，走到所有商店再回來，最少要走多少距離。

每筆測資會給：

- `n`：商店數量
- 接下來有 `n` 個整數，代表每間商店的位置

其實不用真的模擬怎麼走。  
只要知道最左邊的商店和最右邊的商店就好。

因為最短走法一定是：

1. 從某個地方走到最左邊
2. 再走到最右邊
3. 最後回到停車位置

所以答案就是：

```txt
(最大位置 - 最小位置) * 2
```

---

## 錯誤程式碼

```cpp
#include<iostream>

using namespace std;

int main(){
    int t;
    cin>>t(t--)

    return 0;
}
```

---

## 錯誤原因

這份程式主要是還沒有寫完，而且有語法錯誤。

這行是錯的：

```cpp
cin>>t(t--)
```

`cin` 只能用來讀資料，例如：

```cpp
cin >> t;
```

如果要跑 `t` 筆測資，應該另外寫：

```cpp
while (t--) {
    // 每筆測資的程式
}
```

另外，這題還需要讀入：

1. 商店數量 `n`
2. 每個商店的位置
3. 找出最小位置和最大位置
4. 輸出 `(mx - mn) * 2`

原本程式只讀到 `t`，所以還沒有辦法處理題目要求。

---

## 正確程式碼

```cpp
#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t;

    while (t--) {
        int n;
        cin >> n;

        int x;
        cin >> x;

        int mn = x;
        int mx = x;

        for (int i = 1; i < n; i++) {
            cin >> x;

            if (x < mn) mn = x;
            if (x > mx) mx = x;
        }

        cout << (mx - mn) * 2 << endl;
    }

    return 0;
}
```

## 心得

這題比很多 UVA 題目簡單，重點不是排序，而是觀察到只需要最大值和最小值。

一開始可能會想說要不要模擬停車、走路、回來，但其實不用。  
只要把最左邊和最右邊的店找出來，距離就是兩者差距的兩倍。

我覺得這題可以練習：

- 多筆測資 `while (t--)`
- 讀入陣列或一個一個讀
- 找最大值和最小值

下次遇到這種「範圍距離」的題目，可以先想想是不是只跟最大最小有關。
